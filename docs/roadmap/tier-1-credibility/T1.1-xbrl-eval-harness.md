# T1.1: XBRL ground-truth eval harness

## Goal

Build an evaluation harness that runs the pipeline on 50 US annual reports (10-K filings) and scores
every extracted value against the company's own SEC XBRL data (machine-readable financial facts filed with
the SEC). Split the corpus into dev and holdout, and commit the first baseline numbers.

## Why

Today accuracy is only measured on synthetic fixtures whose answers we computed ourselves. XBRL facts
are filed by the company alongside the 10-K, so they are independent ground truth, available for free,
for any US filer, with no hand labelling.

## Important facts about the data (verified background; read carefully)

1. **10-K filings on EDGAR are HTML (inline XBRL), not PDF.** Our app reads PDFs. The harness therefore
   renders the filing's primary HTML document to PDF with headless Chromium (Playwright). Rendered PDFs
   have no ruled table lines, so they exercise the `textgrid` path. This is a **different distribution from
   company-published PDFs**. To cover both, the corpus also supports a `local_pdf` column: if set, that PDF
   is used instead of rendering. Put the existing real reports there (Apple, Berkshire, Microsoft,
   Merchants Bancorp) so their company-published PDFs are scored too.
2. **Endpoints** (all JSON except the document itself):
   - Ticker → CIK: `https://www.sec.gov/files/company_tickers.json`
   - Filings list: `https://data.sec.gov/submissions/CIK{cik10}.json`. Use `filings.recent`, whose
     parallel arrays include `form`, `accessionNumber`, `filingDate`, `reportDate`, `primaryDocument`.
   - Document: `https://www.sec.gov/Archives/edgar/data/{cik_int}/{accession_without_dashes}/{primaryDocument}`
   - Facts: `https://data.sec.gov/api/xbrl/companyfacts/CIK{cik10}.json`. Structure:
     `facts → "us-gaap" → <Tag> → "units" → "USD" → [ {start?, end, val, accn, fy, fp, form, filed, ...} ]`.
3. **Match facts to the filing by `accn`** (the accession number with dashes). A 10-K's facts include
   its prior-year comparatives, all carrying the same `accn`. That is exactly what we want.
4. **Do not use the `fy` field to identify the year of a fact.** `fy` is the fiscal year of the *filing*,
   so comparatives carry the same `fy`. Use the year of `end`, which matches our `Period.end_year`.
   *Amended 2026-09-24 by human decision:* the truth year follows how the filing's statements print it.
   Default: `end_year = year(end)`. A filing whose statements print "Fiscal YYYY" with YYYY one less than
   the end-date year gets an explicit `fiscal_year_offset = -1` in `evals/corpus.csv`, and every override
   must cite its evidence (page and exact header text, e.g. HD: p45 and p48 "Fiscal 2025"); no override
   without evidence. Each run prints every filing where `fy − year(latest end date)` differs from the offset in
   use, so a human can check that filing's header. (A pure `fy`-derived offset was tried and rejected:
   Lowe's prints dated headers "January 30, 2026" and Salesforce calls its year ending 2026-01-31
   "fiscal 2026", yet both carry `fy` one lower.)
5. **Duration vs instant.** Income-statement and cash-flow concepts are durations (they have `start`).
   Keep only facts whose `end - start` is 350–380 days, which drops quarterly facts. Balance-sheet concepts
   are instants (no `start`).
6. companyfacts contains only facts **without dimensions** (no segment breakdowns), which is what we want.
7. The SEC requires a descriptive `User-Agent` and ≤10 requests/second. Read the User-Agent from the
   `SEC_USER_AGENT` environment variable; if it is missing, fail with a clear message. Never hardcode it.

If any of facts 2–6 turns out to be false when you look at a real response, **stop and ask**. Do not
work around it silently.

## Design (fixed)

### Package layout

```
src/fincopilot/sources/
    __init__.py
    edgar.py        # network fetch + disk cache. No financial logic.
    render.py       # HTML -> PDF via Playwright. Optional import.
evals/
    __init__.py
    corpus.csv          # committed: which companies
    corpus.lock.json    # committed: which exact filing (accession) per company, written on first fetch
    concept_tags.py     # CanonicalConcept -> accepted us-gaap tags, duration/instant, sign rule
    truth_xbrl.py       # companyfacts JSON + accession -> truth records
    score.py            # AnalysisResult + truth -> outcome records + totals
    run.py              # CLI
    truth/              # committed: frozen truth per filing, <TICKER>_<accession>.json
    results/            # baseline_dev.json committed; latest_*.json gitignored
    .cache/             # gitignored: downloaded HTML, rendered PDFs, companyfacts JSON
```

Add to `.gitignore`: `evals/.cache/` and `evals/results/latest_*.json`.
Add dependency group `eval = ["playwright>=1.45"]` in `pyproject.toml`. Setup commands for the README:
`uv sync --dev --group eval && uv run playwright install chromium`.

### `sources/edgar.py` API

```python
class SourceError(Exception): ...

@dataclass(frozen=True, slots=True)
class Filing:
    cik: str            # 10-digit, zero-padded
    accession: str      # with dashes, e.g. "0000320193-23-000106"
    form: str           # "10-K"
    filing_date: str    # ISO date
    report_date: str    # ISO date (period end)
    primary_document: str

class EdgarClient:
    def __init__(self, user_agent: str, cache_dir: Path, min_interval_s: float = 0.15) -> None
    def cik_for_ticker(self, ticker: str) -> str
    def annual_filings(self, cik: str) -> list[Filing]     # form == "10-K" only, newest first
    def document(self, filing: Filing) -> bytes            # the primary HTML
    def company_facts(self, cik: str) -> dict
```

- Use `urllib.request` from the standard library (no new HTTP dependency).
- Cache every response on disk under `cache_dir`, keyed by `sha256(url)`. A cache hit makes no request.
- Enforce `min_interval_s` between real requests (a monotonic-clock sleep).
- Wrap every network or JSON error in `SourceError` with the URL (no response body) in the message.

### `sources/render.py` API

```python
class RenderUnavailable(Exception): ...
def html_to_pdf(html: bytes, *, base_url: str) -> bytes
```

- Import `playwright.sync_api` **inside** the function; on `ImportError` raise `RenderUnavailable` with
  the install command.
- Write the HTML to a temp file, `page.goto(file_uri)`, then `page.pdf(format="Letter", print_background=False)`.
- Rendering must be deterministic for the eval: cache rendered PDFs in `evals/.cache/pdf/<accession>.pdf`
  and reuse them.

### `evals/concept_tags.py`

A dict `CanonicalConcept -> ConceptTruthSpec(tags: tuple[str, ...], kind: "duration" | "instant",
sign_agnostic: bool)`. Start with exactly this table:

| concept | tags (all accepted, first listed is preferred) | kind | sign_agnostic |
|---|---|---|---|
| revenue | Revenues, RevenueFromContractWithCustomerExcludingAssessedTax, SalesRevenueNet | duration | no |
| cogs | CostOfRevenue, CostOfGoodsAndServicesSold | duration | **yes** |
| gross_profit | GrossProfit | duration | no |
| operating_income | OperatingIncomeLoss | duration | no |
| d_and_a | DepreciationDepletionAndAmortization, DepreciationAndAmortization, DepreciationAmortizationAndAccretionNet | duration | no |
| net_income | NetIncomeLoss, ProfitLoss *(ProfitLoss added 2026-09-24 by human decision: filers whose first "Net income" row is consolidated incl. noncontrolling interests tag it ProfitLoss; which basis the app should use is a known issue)* | duration | no |
| total_assets | Assets | instant | no |
| current_assets | AssetsCurrent | instant | no |
| cash | CashAndCashEquivalentsAtCarryingValue | instant | no |
| total_liabilities | Liabilities | instant | no |
| current_liabilities | LiabilitiesCurrent | instant | no |
| short_term_borrowings | ShortTermBorrowings, DebtCurrent | instant | no |
| long_term_borrowings | LongTermDebtNoncurrent | instant | no |
| equity | StockholdersEquity, StockholdersEquityIncludingPortionAttributableToNoncontrollingInterest | instant | no |
| operating_cash_flow | NetCashProvidedByUsedInOperatingActivities | duration | no |
| capex | PaymentsToAcquirePropertyPlantAndEquipment | duration | **yes** |

Not scored: `ebitda`, `total_debt`, `free_cash_flow` (derived in the app; no single XBRL tag). A
concept that is missing from this table is never scored.

Why "accept any listed tag": companies choose between equivalent tags. Accepting a set is honest only
because each set contains concepts that are the same line item under different names. Record which tag
matched, so that the choice can be reviewed later.

### `evals/truth_xbrl.py`

```python
@dataclass(frozen=True, slots=True)
class TruthValue:
    concept: str          # CanonicalConcept.value
    end_year: int
    values: tuple[str, ...]   # accepted values as Decimal strings, one per matching tag (deduplicated)
    tags: tuple[str, ...]

def truth_for_filing(facts: dict, accession: str) -> tuple[list[TruthValue], list[str]]
    # returns (truth values, notes). Notes list every exclusion and why.
```

Rules:

- For each concept and each of its tags, take the `units.USD` facts with `accn == accession` that satisfy
  the duration/instant rule.
- Group by `end` year. If one tag gives **two different** values for the same end year, exclude that
  (concept, year) and add a note. Never pick one.
- Write the result to `evals/truth/<TICKER>_<accession>.json` (pretty JSON, sorted keys). Once written,
  the eval reads the frozen file instead of recomputing it, so SEC amendments cannot silently move the truth.

### `evals/score.py`

```python
def score(result: AnalysisResult, truth: list[TruthValue]) -> list[OutcomeRecord]
```

For each truth value (concept, end_year):

1. Find the **mapped** app value: an item in `result.mapping.values` with the same concept and
   `period.end_year`. Only mapped values are scored; derived ones are not.
2. None found → `withheld`. Record the reason by looking up `result.metric_set.unavailable` with the key
   `(concept.value, Period(end_year=y, label=""))`. The key's first element is the concept's **string value**,
   and `Period` equality ignores `label`. Use `Unavailable.root()` for the reason and detail. If there is no
   entry, the reason is `"not_mapped"`.
3. Found → tolerance `= SCALE_MULTIPLIER[fv.cell.scale] / 2` (half of the smallest printed unit). Compare
   against each accepted truth value:
   - `|app - t| <= tol` for some t → `correct`.
   - else if `sign_agnostic` and `||app| - |t|| <= tol` → `correct`.
   - else if `||app| - |t|| <= tol` → `wrong` with `sub="sign_mismatch"`.
   - else if the app value matches the truth of the **same concept, different end_year** → `wrong`,
     `sub="wrong_period"`.
   - else → `wrong`, `sub="value"`.
4. Also report app mapped values that have no truth record as `unverified` (not in any ratio).

`OutcomeRecord` fields: `ticker, accession, concept, end_year, outcome, sub, app_value, truth_values,
tags, ref_id, row_label, page, reason`. All numbers are strings.

Totals and ratios exactly as defined in `tier-1-credibility/README.md`. Also compute per concept and per
filing.

### `evals/corpus.csv`

Columns: `ticker,bucket,sector,local_pdf`. `bucket` ∈ {`general`, `financial`}. Financial companies are
scored and reported **separately**: banks and insurers lack a classified balance sheet, so mixing them in would
make coverage misleading.

Seed list (50). Write it exactly:

- general: AAPL, MSFT, GOOGL, AMZN, META, NVDA, ORCL, CSCO, IBM, INTC, ADBE, CRM, KO, PEP, PG, WMT, COST,
  HD, NKE, MCD, SBUX, JNJ, PFE, MRK, ABBV, UNH, XOM, CVX, CAT, DE, HON, BA, UPS, LMT, T, VZ, DIS, NFLX, TSLA, F, GM, LOW
- financial: JPM, BAC, WFC, GS, BRK-B, MET, AIG, MBIN

Set `local_pdf` for AAPL, MSFT, BRK-B, MBIN to the file names in `tests/fixtures/real/`
(`apple_10k_2023.pdf`, `microsoft_fy24.pdf`, `berkshire_2023.pdf`, `merchants_bank_2024.pdf`). For those four,
the lock file must record the **accession of the 10-K that PDF is**, not the latest one. Find it by
matching `reportDate` to the fiscal year in the file name.

**Filing selection** for everyone else: the most recent 10-K with `filingDate <= 2026-06-30`. Record the
result in `corpus.lock.json` on first run; later runs read the lock and never re-select.

**Split:** `holdout` if `int(sha256(ticker).hexdigest(), 16) % 10 < 3`, else `dev`. It is deterministic and
never hand-edited. Print the split counts at the start of each run.

### `evals/run.py` CLI

```
uv run python -m evals.run [--split dev|holdout|all] [--bucket general|financial|all]
                           [--only TICKER ...] [--compare PATH] [--workers N]
```

- Default: `--split dev --bucket all --workers 1`.
- Flow per company: lock → fetch (cache) → PDF (`local_pdf` if present and on disk, else render) →
  `pipeline.analyze(pdf_bytes)` with **no LLM** → frozen truth → `score`.
- If a company fails to fetch, render or analyse: record `status=error` with the exception class and
  message, and continue. Errors are counted and printed; they are never silently dropped.
- Writes `evals/results/latest_<split>.json` (full records + totals + git SHA + timestamp).
- Prints a Markdown summary: totals table, per-concept table sorted by `wrong` desc, and the list of
  every `wrong` record (ticker, concept, year, app vs truth, row label, page).
- `--compare PATH`: prints deltas vs that file and **exits 1 if `wrong` increased or precision fell**.

## Steps

1. Add the `eval` dependency group, gitignore entries, and the `network` pytest marker (deselected by default).
2. Implement `sources/edgar.py` + `tests/test_sources_edgar.py`. Unit tests use a fake opener (inject the URL
   opener into the client; don't monkeypatch `urllib` globally) and cover: cache hit makes no request,
   User-Agent header is sent, missing `SEC_USER_AGENT` → clear error, 10-K filtering, rate-limit spacing
   (inject the clock).
3. Implement `sources/render.py` + one test that is skipped when Playwright is not installed. It renders a tiny
   HTML table and asserts the output starts with `%PDF-` and that `pipeline.analyze` does not raise an

   Accept that exception.)
4. Implement `evals/concept_tags.py`, `evals/truth_xbrl.py` + `tests/test_evals_truth.py`, using a
   **hand-written** companyfacts excerpt in `tests/fixtures/evals/companyfacts_min.json`. Cover: accn filter,
   quarterly facts dropped, instant vs duration, same-tag conflicting values → excluded with a note,
   multiple tags → both values accepted, `fy` ignored in favour of `end` year.
5. Implement `evals/score.py` + `tests/test_evals_score.py` with hand-built `FinancialValue`s (use
   `FinancialValue.from_cell` with a `NormalizedCell`; see how existing tests build them in `tests/helpers.py`).
   Cover every outcome: correct at exactly the tolerance boundary, wrong just past it, sign_mismatch,
   sign_agnostic correct, wrong_period, withheld with a reason, unverified.
6. Implement `evals/corpus.csv`, the split, the lock file logic, and `evals/run.py`.
7. **Pilot:** `uv run python -m evals.run --split all --only AAPL MSFT KO XOM JPM`. Open two rendered PDFs
   and confirm the statements are readable. For AAPL, check three `correct` values and one
   `withheld` value by hand against the filing. **Paste this hand check into the log.** It is the harness's
   own validation.
8. **Full run:** `--split dev`, then `cp evals/results/latest_dev.json evals/results/baseline_dev.json` and
   commit. **Do not run holdout** (the tier exit gate does that).
9. Write `evals/README.md`: what the harness measures, the definitions, the rendered-vs-published PDF caveat,
   how to run it, and the fact that it measures only the 16 concepts in `concept_tags.py`.
10. Update the root README (a short "Accuracy evaluation" section pointing at `evals/README.md`; say plainly
    that numbers are published at the end of tier 1) and `docs/KNOWN_ISSUES.md` (add the rendered-PDF
    distribution caveat).

## Acceptance criteria

1. `uv run pytest -q` passes without network access; network tests are deselected by default.
2. The pilot of 5 companies completes, and the log contains the hand check of 3 correct + 1 withheld AAPL values.
3. Full dev run completes; `baseline_dev.json` is committed with totals, per concept, per filing, and every
   record; errors (if any) are listed with their cause.
4. Every `wrong` record in the baseline lists row label, page, app value and truth value(s).
5. `--compare evals/results/baseline_dev.json` on an unchanged tree exits 0 and shows zero deltas.
6. `scripts/snapshot.py --check` shows **no diff** (this phase changed no product behaviour).
7. No new `urllib` use outside `src/fincopilot/sources/edgar.py` (`src/fincopilot/ai/client.py` predates
   this phase). Check: `grep -rn "urlopen\|urllib" src/ evals/` hits only `sources/edgar.py` and
   `ai/client.py`. (Amended 2026-09-24 by human decision.)

## Phase-specific checks

- Evaluator: pick **three `wrong` records at random** from the baseline and check them by hand
  against the filing (the rendered PDF and the XBRL value). Classify each as a real app error or a
  harness/truth error. If any is a harness error, the phase **fails**: fix the harness, not the app.
- Evaluator: pick two `correct` records and confirm them by hand as well.

## Stop and ask if

- Any "important fact" above is false for a real response.
- More than 20% of companies end in `status=error`.
- The pilot's AAPL hand check disagrees with the harness.

## Subagent split

Builder A: steps 1–3 (sources). Builder B (can run in parallel): steps 4–5 (truth + score, pure logic,
no network). Then one builder for steps 6–10. The evaluator runs the gate plus the six-record hand check.

# T3.2: Peer comparison

## Goal

Compare 2–3 companies side by side for their latest year: margins, returns, liquidity, leverage, cash
backing of profit, and red flags. Every cell stays traceable to its own document and cell.

## Prerequisites

T3.1 merged (so a bank compared with a manufacturer shows "not applicable" instead of misleading gaps).

## Read first

- `src/fincopilot/calc/series.py` and the Multi-year tab (T2.4): the document-identity pattern to reuse
- `src/fincopilot/views.py`, `charts.py`, `panel.py`
- `src/fincopilot/profile.py` (T3.1)

## Decision step (answer first; record the answer in the log)

Companies reporting in different currencies (e.g. Infosys in INR vs Apple in USD):

- **A. Compare ratios only; hide absolute amounts** (recommended). Ratios are currency-free; absolute
  amounts are shown per company in its own currency, never side by side on one axis.
- **B. Refuse the comparison.**
- **C. Convert currency.** **Not allowed.** The README says "No currency conversion, ever." Listed only so it
  is explicitly rejected.

## Design (assuming A)

1. Input: 2–3 analysed documents (upload or ticker), **one per company**. Their latest periods may differ; each
   column is labelled with its own period (e.g. "Apple FY2023", "Microsoft FY2024"). No alignment by calendar year.
2. `src/fincopilot/compare.py` (pure): `build_comparison(items: Sequence[tuple[str, AnalysisResult]]) ->
   Comparison`, with rows = the metric names in `calc/ratios.py` + red-flag rule IDs, columns = companies,
   and cells = `SourcedFigure | Unavailable` (reuse the T2.4 type).
3. Absolute amounts (revenue, net income, total assets) appear only when all companies share a currency;
   otherwise their row shows per-company values with currency codes and the note "different currencies,
   not compared".
4. UI: a **Compare** tab (shown when ≥2 companies are loaded and the user chooses "compare companies" instead
   of "same company, multiple years"; the two modes are mutually exclusive, and the UI asks which). Show a
   table, one grouped bar chart per ratio family, and red-flag rows as fired/clear/not evaluated. "Show source"
   uses the T2.3 viewer for the right document.
5. Profiles differ (bank vs general) → show a banner explaining that some rows are not applicable to some
   companies.

## Steps

1. Decision logged.
2. `compare.py` + `tests/test_compare.py`: mixed currency hides the absolute comparison; different fiscal
   periods are labelled, not aligned; an unavailable metric carries its root cause; document identity is kept.
3. UI + app tests (mode selection, the tab appears, source links go to the right document).
4. Manual check: AAPL vs MSFT vs GOOGL via the ticker flow. Verify 5 ratio cells by hand against the documents.
5. README section + screenshot.

## Acceptance criteria

1. Snapshot and dev eval unchanged.
2. No code path multiplies or divides amounts across two different documents' currencies (reviewed and stated in the log).
3. The manual check is recorded.
